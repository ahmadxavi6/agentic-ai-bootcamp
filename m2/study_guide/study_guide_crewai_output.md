# Study Guide: temperature in language models (CrewAI)

## Explanation
In language models, temperature is a setting that controls how creative or random responses are. A low temperature produces safer, more consistent answers, while a high temperature increases variation and novelty. Choosing the right value depends on whether you want precision or creativity.

## Example and misconception
Example: For customer-support replies, temperature 0.2 keeps responses stable and clear; for brainstorming ad ideas, temperature 0.9 can produce more original suggestions.
Misconception: "Temperature changes model intelligence." It does not; it mainly changes response randomness.

## Quiz
Q1: What is the main role of temperature in a language model?
A) It changes the model size
B) It controls response randomness
C) It changes the training dataset
A1: B) It controls response randomness

Q2: Which setting is usually better for precise, consistent outputs?
A) Low temperature
B) High temperature
C) Maximum temperature
A2: A) Low temperature

Q3: Which statement is true about high temperature?
A) It always improves factual accuracy
B) It often increases creativity and variability
C) It disables context usage
A3: B) It often increases creativity and variability
